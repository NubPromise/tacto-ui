移动端组件与设计规范

零构建、原生 CSS 与 ES Modules。共享设计令牌与基础样式，按需加载组件；支持深浅色、高对比度、减少动画与减少透明度偏好。

层级规则：内容区一律用实色卡 + 柔和阴影；玻璃只给控制层（导航、悬浮按钮、弹层）。这条规则决定了整站的视觉重心——内容实、控件轻。

排版

字号角色覆盖 28px 页面大标题至 12px 辅助信息与导航标签。字重取中间档（650 / 550 / 450），可变字体呈现对应字重，静态字体使用设备回退。

按钮

四种变体、三种尺寸。最小高度 48px 保证触控目标；一屏内只允许一个主按钮。按压用缩放（scale 0.96）而非变色，保持颜色语义稳定。

变体.ui-btn · --primary · --ghost · --danger
尺寸--sm · 默认 · --lg · --block
状态:disabled · .is-loading · [aria-pressed]
组合与整宽.ui-btn-group · --block
无障碍：图标按钮必须有 aria-label；加载态用 .is-loading 并配合 aria-busy="true"；不可用用原生 disabled，不要只用透明度模拟。

表单字段

输入框高度不低于 48px、字号不低于 16px（避免 iOS 聚焦时自动放大页面）。标签必须可见，不用 placeholder 代替标签；错误用「边框变色 + 文字说明」双通道。

下拉选择

原生 <select> 的弹层无法定制，这里用按钮 + 列表实现，但按 combobox 模式保留完整键盘操作。焦点始终留在触发器上，用 aria-activedescendant 指向当前项——移动端不会出现键盘弹起又收起。

套餐.ui-select
键盘：↑ ↓ 移动，Enter / Space 选中，Esc 关闭，Home / End 跳首尾。下方空间不足时自动向上展开（.is-up）。

语音条

波形条数与时长相关（每 2 秒一根，3–5 根）。播放中波形用透明度呼吸而不是位移，避免整条抖动。自己的语音反色显示。

状态.ui-voice · --mine · .is-playing · .is-error

分段控件与标签栏

2–5 段用分段控件，超过 5 段改用横向滚动的标签栏。选中态用滑块位移，不用下划线；键盘左右键可切换。

对话框

基于原生 <dialog>，自带焦点陷阱、Esc 关闭与遮罩。危险操作把主按钮换成红色，并把默认焦点放在「取消」上。

点击预览.ui-dialog
规范：标题一句话说清结果，正文补充后果；按钮右对齐、主操作在最右；按钮不超过两个，超过两个改用底部面板的操作表。
全局通用弹窗 · 无需预写 HTMLalert() / confirm()
从 behaviors/index.js 导入 alert / confirm，传入文本或选项对象。返回 Promise<boolean>；只有点击确认才返回 true。多个调用依次显示，默认禁止点遮罩关闭。

底部面板

承载选项组或次级表单。顶角 28px、贴安全区，内容超过 85dvh 时内部滚动。必须支持点遮罩、按 Esc、下滑把手三种关闭方式。

点击预览.ui-sheet · .ui-actions

轻提示

只承载「已经发生」的反馈，不承载需要决策的信息。停留 2.4 秒，同一时刻只显示一个，新提示替换旧提示而不是排队。

点击预览.ui-toast
播报：普通提示用 role="status"（礼貌播报），错误用 role="alert"（立即播报）。不要给两者都加 aria-live="assertive"。

导航

底部胶囊玻璃导航 3–5 项，选中项用「换色 + 加粗」双通道。页面内容要预留 --dock-h 的滚动余量，否则最后一条会被遮住。

骨架屏
